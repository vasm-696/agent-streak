How it works

  • Only addresses holding an Agent ID (SPACE ID Agent ID, ERC-721 on BNB Chain) can check in. The contract checks balanceOf(address) > 0 on the Agent ID contract 0x60b9262456de011f7d15a54cdd8c48baaa8b022f.
  • One check-in per UTC day. Checking in on consecutive days grows your streak; a missed day resets it to 1.
  • Contract: not deployed yet (BscScan). Source verified and open-source on BscScan. The contract has no owner and no admin powers: no pause, no mint, no freeze, no tax, no withdraw, no upgrade.
  • Agentic Wallet users: open this page inside the Binance App browser. This site never asks for a seed phrase, private key, API secret or pairing code, and never uses QR-code login.
  • This project is not affiliated with or endorsed by Binance. It does not look up wallets by Agent ID name.
